# Day 08：Dense + Sparse 混合检索

## 今日目标

在向量语义检索之外加入关键词检索，并通过融合策略改善专有名词、编号和精确关键词的召回。

## 今日时间表

1. 09:00-10:30：比较 Dense、Sparse 和关键词检索。
2. 10:45-12:00：建立 BM25 或 Sparse 检索索引。
3. 14:00-15:30：实现两路并行召回。
4. 15:45-17:00：实现 RRF 融合与去重。
5. 17:00-18:00：运行 Day 07 评估集并比较。

## 必学知识

- `【非常重点】Dense Search`：擅长语义相似，但可能忽略精确编号和罕见词。
- `【非常重点】Sparse/BM25`：擅长关键词匹配，但近义表达能力弱。
- `【非常重点】Hybrid Search`：两路召回后融合，而不是简单拼接。
- `【非常重点】RRF`：使用排名而非不同量纲的原始分数进行融合。
- `【重点】去重`：同一 Chunk 可能被多路召回，只保留一个候选。

## 编码任务

1. 为相同 Chunk 建立 Dense 和 Sparse 索引。
2. 两路分别召回候选集并保留原始排名。
3. 使用 RRF 计算融合排名。
4. 用 `document_id + chunk_id` 去重。
5. 对编号、术语、近义句和普通问题分别比较结果。

## 验收标准

- 能展示两路召回和融合后的三个结果列表。
- 精确术语类问题不低于原 Baseline。
- 使用 Day 07 相同评估集输出对比报告。
- 对指标没有提升的样本给出原因，而不是盲目调参。
