# Day 12：Vue 前端联调与完整演示流程

## 今日目标

完成最小但完整的浏览器操作界面，让面试官无需阅读代码即可体验项目能力。

## 今日时间表

1. 09:00-10:00：确定演示流程和页面状态。
2. 10:00-12:00：完成文档上传、列表和处理状态。
3. 14:00-15:30：完成对话和 SSE 渲染。
4. 15:45-17:00：完成引用定位和人工确认界面。
5. 17:00-18:00：桌面与移动端联调。

## 必学知识

- `【非常重点】完整状态`：上传中、处理中、可用、失败、空结果和网络错误都必须可见。
- `【非常重点】引用展示`：答案中的引用可展开查看来源文档和片段。
- `【非常重点】人工确认`：写操作必须展示将执行的参数，并提供确认与取消。
- `【重点】流式状态管理`：同一消息持续追加 Token，断线或取消后正确收尾。
- `【重点】演示路径`：用户三分钟内能看到上传、问答、引用和 Agent 操作。

## 页面范围

只完成求职演示所需页面：

1. 知识库文档管理。
2. Agent 对话页面。
3. 引用详情抽屉。
4. 待执行操作确认对话框。
5. 简单的评估结果展示或项目指标入口。

## 验收标准

- 上传后无需刷新即可看到处理状态。
- 流式回答不会造成重复文本或顺序错乱。
- 引用可以定位到原始来源。
- 用户取消操作后后端数据不变。
- 所有错误都有明确、可恢复的界面状态。
