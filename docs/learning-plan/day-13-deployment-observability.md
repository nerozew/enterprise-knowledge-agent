## 今日目标

## 必学知识

- `【非常重点】可重复部署`：新机器只依赖文档、环境变量和 Compose 即可启动。
- `【非常重点】健康检查`：Liveness 表示进程存活，Readiness 表示依赖可用。
- `【非常重点】可观测性`：一次请求应能关联 API、Graph 节点、检索、模型、工具和错误。
- `【非常重点】秘密管理`：`.env`、API Key、数据库密码绝不提交 Git。
- `【重点】持久化卷`：MySQL、Milvus、MinIO 和 Redis 的数据策略必须明确。

## 编码与运维任务

1. 为前后端建立多阶段镜像。
2. 配置服务健康检查和依赖启动条件。
3. Nginx 提供 HTTPS、静态资源、API 反向代理和 SSE 配置。
4. 接入 LangSmith 或 Langfuse，并记录 Token、耗时和错误。
5. 模拟模型超时、Milvus 不可用和容器重启。

## 验收标准

- 在线地址可完成登录、上传、问答和引用查看。
- 服务器重启后业务数据仍然存在。
- 日志中不存在密钥和完整隐私正文。
- 可以通过 Trace 找到慢请求耗时在哪个步骤。
- README 中有从零部署和回滚步骤。
