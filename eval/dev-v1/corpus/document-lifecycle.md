# 草稿与发布

协同编辑中的内容属于可变草稿。草稿只对具备编辑权限的成员可见，不能进入企业检索，也不能
成为回答引用。只有用户显式执行“发布”后，系统才生成不可变的发布版本并进入检索索引。

新版本发布失败时，系统必须继续使用上一个成功发布版本。索引完成并校验 Chunk 数量后，MySQL
在单一事务中切换当前发布指针。历史回答引用固定到当时的发布版本和 source span，后续编辑
不能改变旧引用的含义。

# 删除与保留

删除逻辑文档首先执行软删除，普通搜索立即不可见。管理员可在 30 天保留期内恢复。超过保留期
后由清理任务删除对象和向量；清理失败必须记录补偿任务，MySQL 中的删除事实不能回滚成可见。
