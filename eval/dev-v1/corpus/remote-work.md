# 远程办公

员工每周最多可申请 2 天常规远程办公，并提前一个工作日在考勤系统登记。涉及现场设备、保密
会议或客户明确要求到场的工作不适用常规远程安排。连续远程超过 5 个工作日需要部门负责人批准。

# 终端设备

访问公司源码、客户数据和生产系统必须使用受管设备。受管设备必须开启磁盘加密、自动锁屏、
终端检测与响应软件，并及时安装安全更新。公共电脑和家庭成员共用设备不得访问公司数据。

# 网络与遗失

公共 Wi-Fi 下必须使用公司 VPN，禁止绕过证书告警。设备遗失或疑似被盗后，员工应在 30 分钟内
通知 IT 服务台和直属负责人，以便远程锁定、撤销会话并评估数据影响。
