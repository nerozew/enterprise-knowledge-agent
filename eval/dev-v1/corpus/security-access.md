# 生产系统访问

生产权限采用最小权限原则。员工必须先提交工单，写明系统、角色、业务理由和预计结束时间。
直属负责人和系统 Owner 均批准后，平台才可授予权限。普通生产访问最长有效 30 天，到期自动
回收；需要继续使用时必须重新申请。

紧急故障可以申请 Break Glass 临时权限。值班负责人批准后权限立即生效，但最长只能保留
2 小时。申请人必须在故障结束后 24 小时内补充事故编号、执行命令摘要和影响说明，安全团队
每周复核所有紧急授权。

# 密钥管理

API Key、数据库密码和私钥不得写入源码、工单正文、聊天消息或普通日志。应用凭据统一保存到
密钥管理服务，通过运行身份动态读取。发现疑似泄露后应在 15 分钟内轮换相关密钥，并创建
安全事件记录。

生产数据库禁止使用共享个人账号。自动化服务使用独立服务身份，权限变更和高风险查询都必须
写入不可变审计日志，日志至少保留 365 天。
